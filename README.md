# vivekjudemanoj.vercel.app

My personal site: experience, projects and hackathons, with a focus on infrastructure and developer tooling.

**Live:** https://vivekjudemanoj.vercel.app

## Stack

- Next.js 14 (App Router) and TypeScript
- Tailwind CSS
- Framer Motion for the shared-layout panels and animations
- Deployed on Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

All text, links and media live in `components/data/index.ts`. Media goes in `public/media/<project>/`, and a project's images or videos appear on its page once the file exists.
